确保存在以下目录：

用户目录/.local/share/Terraria/tModLoader/Mods/

用户目录/.local/share/Terraria/tModLoader/Worlds/

将tModLoader.zip解压至以下文件夹：

用户目录/tmodloader/

Debian和Ubuntu可以直接运行tmodtask.sh
